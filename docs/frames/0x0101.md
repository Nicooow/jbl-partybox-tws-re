# 0x0101 — TWS state broadcast (role/state + channel + level)

BESAUD command `0x0101` is the **periodic TWS/peer state broadcast**. The local side samples a
few bytes out of its live context (`ctx+9`, `ctx+0x18`) plus caller-supplied parameters and
ships them to the peer; the peer mirrors most of them straight back into its own context and
then echoes the whole 18-byte frame as the reply. It is a *push snapshot*, not a request: there
is no query, and the only "answer" is the generic 0x81 ack that every command gets.

* Firmware: `extracted/payload_1.bin` (BES2000IK), Thumb, load base `0x3C000000`. File offset = VA − `0x3C000000`. The same bytes are aliased at `0x0C000000` (Δ `0x30000000`).
* Shared context `ctx = 0x2002F31C` (same literal used by 0x0103/0x0109/0x010C; here it is the pool word `_DAT_3c01ad90` / `iRam3c01a508`).
* Frame envelope: `[type][cmd16 LE][payload…]`; `0x80`=command, `0x81`=ack/response. `FUN_3c019fe0` prepends the type byte, so the builder's 18-byte buffer is `[cmd16][16 payload bytes]`.
* Evidence status: **static reverse engineering only** (not live-injected). Addresses are VA.

## Wire format

### Outbound — speaker → peer (builder `FUN_3c01ad18`, file `0x1AD18`)

`void FUN_3c01ad18(byte param_1, byte param_2, byte param_3, u32 param_4, byte param_5)`.
It first derives the **channel/mode** byte `uVar2` from live state:

```c
if      (*(char*)(ctx+9) == 1) uVar2 = (*(char*)(ctx+0x18) == 2) ? 2 : 3;
else if (*(char*)(ctx+9) == 2) uVar2 = (*(char*)(ctx+0x18) == 2) ? 2 : 4;
else                           uVar2 = 2;
```

then fills an 18-byte stack buffer and calls `FUN_3c019fe0(&buf, 0x12, 1000)` (cmd type `0x80`,
18-byte body, wait ≤1000 ms for the peer's ack). After sending it writes `ctx+0x18 = uVar2`.
Total on the wire = **19 bytes**. Buffer map (offsets are relative to the buffer = wire offset − 1):

| buf off | payload # | size | field | value / semantics |
|---|---|---|---|---|
| 0 | — | 2 | cmd16 (LE) | `01 01` = `0x0101` |
| 2 | 0 | 1 | reserved | `0x00` |
| 3 | 1 | 1 | state byte A = `param_1` | → peer `ctx+0x300`/`ctx+0x301`; AGENTS.md sees `0x03` here at connect |
| 4 | 2 | 1 | state byte B = `param_2` | → peer `ctx+0x306` |
| 5 | 3 | 1 | state byte C = `param_3` | → peer `ctx+0x16` |
| 6 | 4 | 1 | reserved | `0x00` |
| 7 | 5 | 1 | channel mode = `uVar2` | `2`=L+R(stereo), `3`=L, `4`=R (role-mapped) |
| 8 | 6 | 1 | level/value = `param_5` | → peer `ctx+0x304` via `FUN_3c020b70` |
| 9 | 7 | 1 | aux = `0x00` | second arg of `FUN_3c020b70` |
| 10–11 | 8–9 | 2 | reserved | `0x00` |
| 12–13 | 10–11 | 2 | reserved | `0x00` |
| 14–17 | 12–15 | 4 | 32-bit value = `param_4` (LE) | → peer `ctx+0x228` **and** global `0x2002A840` |

Disassembly corroborates the layout exactly (`add r0,sp,#4` = buffer base; `strh.w sb(0x101),[sp,#4]`;
`strb.w param_1,[sp,#7]`; `strb param_2,[sp,#8]`; `strb param_3,[sp,#9]`; `strb uVar2,[sp,#0xb]`;
`strb param_5,[sp,#0xc]`; `str.w param_4,[sp,#0x12]`).

### Inbound — peer → speaker (handler `parse_cmd` case @ `0x3C01A2A0`)

`parse_cmd = FUN_3c01a1f4` dispatches via `TBH` at `0x3C01A20A` (base `0x3C01A20E`), index `cmd16−0x100`.
`param_1` is a `u16*` on the buffer (= wire offset 1). The handler reads five fields:

| buf off | read as | field | action |
|---|---|---|---|
| 0–3 | `*(u32*)param_1` | cmd16 + byte 3 | byte 3 used (see below) |
| 4–7 | `*(u32*)(param_1+2)` | state bytes 4/5/7 | bytes 4, 5, 7 used |
| 8–11 | `*(u32*)(param_1+4)` | level bytes 8/9 | used |
| 12–15 | `*(u32*)(param_1+6)` | (bytes 12/13 unused) | |
| 16–17 | `param_1[8]` | value 16/17 | used |

Mirroring is **gated on the local role**: the whole mirror block runs only when `*(char*)(ctx+9) == 2`.

```c
case 0x101:
  if (*(char*)(ctx+9) == 2) {
    ctx+0x300 = buf[3];  ctx+0x301 = buf[3];
    ctx+0x306 = buf[4];
    ctx+0x228 = *(u32*)(buf+14);                       /* bytes 14..17 */
    ctx+0x18  = buf[7]==3 ? 4 : (buf[7]==4 ? 3 : 2);   /* role-mirrored channel */
    FUN_3c020b70(buf[8], buf[9]);                      /* apply level/value */
    *(u16*)(ctx+0x304) = (u16)(buf[8]);                /* level readback */
    func_0x3c01c7b0(*(u32*)(buf+14));                  /* 0x2002A840 = value */
  }
  ctx+0x16 = buf[5];                                   /* always */
  FUN_3c01a08c(buf, 0x12);                             /* 18-byte type-0x81 ack */
```

**Reply.** Unlike most cases (which fall through to the shared `FUN_3c01a08c` tail echoing only
the cmd16), `0x0101` calls `FUN_3c01a08c` itself with the recomposed buffer, so the ack body
**echoes the received state**, not stale stack.

## Field / direction map (consolidated)

| field | outbound writer | inbound reader | meaning |
|---|---|---|---|
| 1 (`buf3`) | `param_1` | → `ctx+0x300` & `ctx+0x301` | connection/state byte (`0x03` at connect) |
| 2 (`buf4`) | `param_2` | → `ctx+0x306` | secondary state byte |
| 3 (`buf5`) | `param_3` | → `ctx+0x16` (always) | per-frame peer state byte |
| 5 (`buf7`) | `uVar2` (from `ctx+9`+`ctx+0x18`) | → `ctx+0x18` (swap 3↔4) | channel: 2=L+R, 3=L, 4=R |
| 6 (`buf8`) | `param_5` | → `ctx+0x304` + `FUN_3c020b70` | level/value (clamped 0..0x20) |
| 7 (`buf9`) | `0` | 2nd arg of `FUN_3c020b70` | aux level arg |
| 12–15 (`buf14..17`) | `param_4` (u32) | → `ctx+0x228` + `func_0x3c01c7b0` | 32-bit token/state |

## `ctx` fields referenced

* **`ctx+9`** — the *committed link role*, `1` or `2` (see Call chain). It selects the channel
  encode on send and gates the whole receive-side mirror. Values other than 1/2 force channel `2`.
* **`ctx+0x18`** — the **local channel mode**: `2`=L+R, `3`=L, `4`=R. The builder encodes it onto
  the wire (via `uVar2`) *before* overwriting it; the handler decodes it from the wire using the
  role-dependent 3↔4 swap, so the two peers store mirrored channels.
* **`ctx+0x16`** — the **peer's state byte**, copied unconditionally from field 3. The same field
  is written by the 0x0106 and 0x0107 handlers from their `buf[5]`, and read back in 0x0107
  (`func_0x3c01fa58(obj, ctx+0x16)`), i.e. it is a shared "last reported state" slot.
* **`ctx+0x300` / `ctx+0x301`** — connection-state bytes (both set from field 1; 0x0107 also writes
  `ctx+0x300/0x301`). **`ctx+0x306`** — secondary state byte (mirrors `ctx+0x300` in 0x0106/0x0107).
* **`ctx+0x228`** — 32-bit value from fields 12–15 (kept in lock-step with the global below).
* **`ctx+0x304`** — the applied level/value (u16).

## Helper functions

| function | file | role |
|---|---|---|
| `FUN_3c020b70(u16 value, u32 aux)` | `0x20B70` | **level/value setter.** Pushes `(char)value` into a subscriber buffer (`func_0x3c01ca78(3)`/`func_0x3c01ca6c()`/`func_0x3c016428`), stores `value` at `ctx+0x304`, clamps it to `[0,0x20]` and writes the clamped value through `*_DAT_3c01c91c`, then applies it with `FUN_3c042154(v)` + `func_0x3c046384(v,0,aux)`. AGENTS.md ties this function / `ctx+0x304` to the **volume level (0..32)**. |
| `func_0x3c01c7b0(u32 v)` | `0x1C7B0` | tiny setter: `*(u32*)0x2002A840 = v; bx lr`. Its sibling `func_0x3c01c7bc` (`0x1C7BC`) is the getter `return *(u32*)0x2002A840`. So `ctx+0x228` and `0x2002A840` hold the same 32-bit token. |
| `FUN_3c01a08c(buf, len)` | `0x1A08C` | generic `0x81` ack sender (type `0x81`, body = `len` bytes). Here it echoes the received frame. |
| `FUN_3c019fe0(buf, len, timeout)` | `0x19FE0` | generic `0x80` command sender; gated on `*(u32*)(ctx+0x310) != 0` (live session), waits ≤`timeout` ms for the ack. |

## Emitted side — who calls the builder

The builder is reached from the app event loop `FUN_3c012e84` (file `0x12E84`) as **event `0x01`**:

```c
case 1:
  FUN_3c01ad18( msg[4], msg[5], msg[6], *(u32*)(msg+8), (s8)msg[7] );
```

so the queued event-`0x01` message is laid out `[0]=1, [4]=param_1, [5]=param_2, [6]=param_3,
[7]=param_5, [8..11]=param_4`. Actual transmission is gated inside `FUN_3c019fe0` on a live TWS
session handle at `ctx+0x310`; with `0x310 == 0` the post is a no-op.

## Call chain

| function | file | role |
|---|---|---|
| `FUN_3c012e84` | `0x12E84` | event loop; `case 1` (event `0x01`) → `FUN_3c01ad18` |
| `FUN_3c01ad18` | `0x1AD18` | outbound builder (state + channel + level + token) |
| `FUN_3c019fe0` | `0x19FE0` | `0x80` sender (session-gated, ack wait) |
| `FUN_3c01a1f4` | `0x1A1F4` | `parse_cmd`; `0x0101` → `0x3C01A2A0` |
| `FUN_3c01a08c` | `0x1A08C` | `0x81` ack sender (echoes the frame) |
| `FUN_3c020b70` | `0x20B70` | level/value setter (clamped 0..0x20) |
| `func_0x3c01c7b0` | `0x1C7B0` | `*(u32*)0x2002A840 = v` |

`ctx+9` is set by the event loop's role-switch (`case 0x0D`, writes `ctx+8`) and copied
`ctx+9 = ctx+8` by the full-teardown handler `FUN_3c01abc8` (event 6); `ctx+8` ∈ {1,2} is the
current role and {3,4} the post-teardown state. That is why `ctx+9` works as "the role the
0x0101 channel mapping is keyed on".

## Confidence & unknowns

**Confident (disassembly + constants):**
* Outbound body is `01 01 00 <p1> <p2> <p3> 00 <chan> <lvl> 00 00 00 00 00 00 <u32>` (18 bytes),
  wire type `0x80`, ack wait 1000 ms; buffer addresses verified from `FUN_3c01ad18` disassembly.
* Inbound mirrors only when `*(u8*)(ctx+9) == 2`; `ctx+0x16` is written unconditionally; the ack
  echoes the frame (not stale stack).
* `func_0x3c01c7b0(v)` is literally `*(u32*)0x2002A840 = v`; `FUN_3c020b70` clamps to `[0,0x20]`.

**Inferred (labelled):**
* `ctx+9`/`ctx+8` are the TWS *roles* (`1`/`2`); the channel 3↔4 swap makes the two peers store
  mirrored channels (each side plays one channel).
* `buf[8]` is a **level** (volume-like, 0..0x20) because it feeds `FUN_3c020b70`/`ctx+0x304`,
  which AGENTS.md labels volume. `buf[14..17]` is a 32-bit token/state (mirrored to a RAM global).
* Field-1 (`ctx+0x300/0x301`) is the connection state; AGENTS.md observed `0x03` there at connect.

**Unknown / not verified:**
* Who queues event `0x01` (and hence what the `param_1..param_5` call-site values are) was not
  located; the builder is only characterised from the event-loop call and its field effects.
* Exact user-facing meaning of `ctx+0x300`/`ctx+0x306`/`ctx+0x228` and of the global `0x2002A840`.
* Whether any peer/version leaves `buf[2]`, `buf[6]`, `buf[9..13]` non-zero (outbound always emits 0).
